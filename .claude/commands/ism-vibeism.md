# /ism-vibeism

Source of truth: `ideas/ism-inktober/day-07-vibeism.md`. Read it before anything beyond `explain`.

## What it is

> Skills get you hired. Vibe makes you stay.

A mirror: your values next to a company's values. Do they line up? People leave jobs when the vibe doesn't match, which wastes time for both sides. Vibeism makes the match visible before the offer is signed.

**Not:** a personality test, a culture-fit filter, or a way to hire look-alikes.

Core tools: the six questions (same values, similar people, feels safe, growth and freedom, pride, honest), the iceberg (said: salary, title, perks / felt: seen, respect, belonging, trust, meaning), the mirror test (better me → stay and love it, same me → stay for money, smaller me → leave), six vibe spectrums.

## Modes (`$ARGUMENTS`)

- **explain** (default) — the ISM in 3 lines plus the mirror test question.
- **mirror `<role/company/offer>`** — run the method:
  1. Ask the user for their needs (or reuse the craft-driven builder profile if it fits them) and up to 3 dealbreakers.
  2. Walk the six questions against what the user knows about the place. Mark unknowns as unknown, never guess.
  3. Place both on the six spectrums. Separate **values** gaps (weigh heavily) from **style** gaps (can be healthy).
  4. Build a need / good sign / warning sign table.
  5. Land on the mirror: better me, same me, or smaller me — and what evidence would flip it.
  6. Suggest 2–3 questions to ask current employees (the reality check), since brand pages fake vibe.
- **page** / **caption** — draft new journal sections or caption variants. Follow `/ism-day` voice rules.
- **build** — summarize the app flow, measurement ideas, risks, and what must happen before code (scribble, home decision via `/kiruk-ism-new` or products registry).

## Rules

- Match on values and work style, never background, age, gender, or anything protected. Say so if a request drifts there.
- No MBTI types. Big Five only, lightly, if at all.
- It is the user's decision. Give the mirror, not a verdict.
