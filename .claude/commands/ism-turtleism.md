# /ism-turtleism

Source of truth: `ideas/ism-inktober/day-10-11-turtleism.md`. Read it before anything beyond `explain`.

## What it is

> Slow at the start. Fast at the end.

Be clear before being fast. A road built fast in the wrong direction still leads nowhere. The turtle's shell has four parts, read clockwise from top left — top half is thinking, bottom half is understanding:

| Part             | Gate                                                                  |
| ---------------- | --------------------------------------------------------------------- |
| **Askism**       | Question first. Who is it for? What is "done"? What must it never be? |
| **Answerism**    | Write every answer down, specifically. Vague answer = not ready.      |
| **Dissectism**   | Peel the idea layer by layer; 10 to 15 layers hide the core.          |
| **Intersectism** | See where layers touch. Change one, see what moves.                   |

Flow: **Ask → Answer → Dissect → Intersect → Build.** Each step is a gate.

**Not:** being slow, overthinking, or a ban on prototypes. Slow thinking, not slow writing.

  - If the `turtle` skill is not available, run the four gates lightly yourself: ask the three Askism questions, write back answers, list the layers, map where they touch, then stop and confirm before building.

## Rules

- Hare vs. turtle: prompt, fix, prompt, fix, lost — vs. ask, understand, build once, it fits.
- No gate is skipped because the next try is "free."
