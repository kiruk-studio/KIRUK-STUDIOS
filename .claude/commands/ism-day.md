# /ism-day

Source of truth: `ideas/ism-inktober/README.md` (series rules). Read it first, then skim the most recent two day notes so the new day does not open the same way.

**Argument**: `$ARGUMENTS` = day number, ISM name, and the raw idea. If any is missing, ask for it in one line. Never invent the idea itself.

## What an ISM day is

One new idea named "\_\_\_\_ism", sketched and journaled on a page by hand, then posted to Instagram as a story. kiruk's daily concept series for Inktober. The journal page is built section by section with doodles beside the text, so it reads like a real journal.

## Procedure

1. **Hear the kirukal.** Restate the raw idea in one breath. Ask one question if the core is unclear (who is it for, what problem, what it is not). Stop there until answered.
2. **Draft the caption** — 2 variants, each with:
   - a relatable hook grounded in a real moment (not a slogan)
   - the ISM in one line, name in caps inside quotes: "EXAMPLEISM"
   - one question to the audience
   - the tag line, varied: "Inktober, day N. ISM project by Kiruk Studio." / "Part of the ISM project from Kiruk Studio."
   - hashtags: `#Inktober #<Name>ism #ISM #KirukStudio`
3. **Draft the journal page** — sections in the flow: title → problem → why it happens → idea → how it works → impact → closing. Each section: small heading, 1 to 3 lines, `Doodle:` note. Offer one visual device that fits (comic-strip storyboard, sticker sheet, diagram, before/after, scale).
4. **Self-check** against the rules below before showing anything.
5. **File it** (only when the user says the day is final): write `ideas/ism-inktober/day-NN-<name>.md` with the same front matter as existing notes, add a row to the README concept table, and offer to write `/ism-<name>` with the `/ism-*` skill shape.

## Voice rules (hard)

- Fits an Instagram story. Very few words.
- No emoji.
- First person, human. Interesting, never over-exaggerated.
- Casual: "guys", "just", "honestly". Never corporate.
- No idea repeated twice in one caption.
- Every line carries meaning. Slogan-only lines get grounded in a real moment or cut.
- Opening structure differs from the last two days.

## Rules

- The hand-drawn page is the founder's. Doodle notes describe what to draw; never generate the drawing as the deliverable.
- Nothing posts automatically. Drafts only (content-pipeline: human-triggered publish).
- No revenue talk in captions (build-in-public).
- Eye-motif: if the page or a derivative becomes a visual artifact on a kiruk surface, flag the eye-motif check.
