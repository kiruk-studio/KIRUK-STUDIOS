# mai ledger

One row per real miss. Each row says what read as fake or was wrong (mistake), why it happened (root cause), what changed (fix), and the check, rule or test that stops it coming back (guard).

When a second row has the same class and root cause, the guard is promoted into a skill rule or a critic check, as an approved diff (ways-of-working decision L + D8). This ledger is for misses inside the engine. Studio-wide misses go to [`LEARNINGS.md`](../../../LEARNINGS.md).
